# Библиотечная система — практическая работа 2

Flutter Web-приложение для каталога книг и справочника авторов.

## Реализовано

- две сущности: `Book` (35 записей) и `Author` (18 записей);
- слои `models`, `repositories`, `state`, `screens`, `widgets`;
- состояние через `provider` и `ChangeNotifier`;
- репозитории в памяти; данные восстанавливаются при перезагрузке;
- отдельные экраны списка и карточки книг/авторов через `go_router`;
- поиск: книги — по названию и ISBN, авторы — по фамилии и стране;
- фильтрация: для книг жанр, издательство и диапазон года; для авторов страна и диапазон года рождения;
- логическое и физическое удаление, восстановление, массовые операции с подтверждением;
- сортировка по заголовкам таблицы, в том числе по трём и более полям;
- пагинация: первая/предыдущая/следующая/последняя страница и выбор размера 10, 25 или 50;
- универсальная таблица `EntityTable<T>` для книг и авторов;
- адаптивная вёрстка: таблица от 600 px и карточки на узком экране;
- адрес хранит условия отбора, например:
  `/books?search=война&genreId=4&sort=year,desc&page=2`;
- задержка поиска 350 мс;
- состояния загрузки, ошибки и пустого результата;
- экран 404.

## Исправление ошибки `deleteMany`

В образце из задания в лямбда-выражении использовалось обращение к индексу
`b[i]`, хотя `b` — это объект `Book`, а не список. Из-за этого проект не
компилируется. В проекте условие исправлено на:

```dart
final i = _books.indexWhere((b) => b.id == id && !b.isDeleted);
```

То есть состояние удаления проверяется у найденной книги `b`; только после
нахождения её индекс `i` применяется для замены записи в списке.

# FocusFrame — система бронирования фотостудии

Текущая практическая реализует каталог залов и фотографов: поиск, фильтрацию, сортировку, постраничный вывод, URL как состояние, адаптивный интерфейс, множественное, логическое и физическое удаление.

Тема рассчитана на дальнейшие ПР3–ПР6 и итоговый проект. Полная схема сущностей, ролей и связей приведена в [`docs/domain_model.md`](docs/domain_model.md).

```powershell
flutter pub get

flutter test
flutter run -d chrome
```
